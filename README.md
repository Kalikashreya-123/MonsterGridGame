# Monster Grid Puzzle 👾

Monster Grid Puzzle is a simple maze game where you have to plan your moves instead of controlling the character directly. You choose directions, create a path, and run it to help your character reach the goal. The challenge is to solve each level using as few moves as possible and earn 3 stars.

## Features

. Choose grid sizes from 4x4 to 10x10.
. Different dungeon themes, tile textures, and character emojis.
. 20 levels with different maze layouts and obstacles.
. Use the arrow keys or on-screen buttons to choose your moves.
. Press Backspace to undo your last move.
. Press Enter to run your planned path.
. Your unlocked levels are saved automatically in the browser.
. Return to the home screen anytime to change your settings.

## How to Play

1. Choose your grid size and theme.
2. Look at the maze and plan your path.
3. Add directions using the arrow keys or on-screen buttons.
4. Press Enter to run your path.
5. Reach the goal using the fewest moves possible to earn 3 stars.

## How to Run

No installation or extra packages are needed.

1. Clone or download this repository.
2. Open the project folder.
3. Open index.html in your browser.
4. Start playing!
